# Generated source references are build inputs

The SDK source checker distinguishes an existing source file from an explicitly
declared generated build input. A declaration does not mean a generator ran,
that an output file exists, that native type identities are qualified, or that
an example compiled or interacted with ROS. Default optional authority is empty.

ABI metadata repair and all eleven Go constraint models. Its aggregate source
report nevertheless failed because twelve relative references were unresolved;
no language compiler command began. The independent 177 DATA-model pass is a
separate result. Neither result promotes that failed SDK attempt.
