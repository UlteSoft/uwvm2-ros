## Complete conversion and error atomicity

Encode reads a genuine valid initialized native object, copies every field to
a private complete canonical record, checks all counts and native ownership,
then invokes the actual complete canonical validator/measurement/writer. It
retains inactive ParameterValue fields and all TypeDescription/source/extra
information fields. Overlarge native values return90. Malformed text UTF-8/NUL (except the exact raw source field),
invalid bool/finite-float or malformed ownership returns22. The destination
bytes and length sentinel stay unchanged on every failure. Canonical bounds
are finite quotas, not changed native declarations or a full unbounded ROS API.

Decode first validates the entire exact canonical input into private storage.
It creates a genuine initialized private C object or original C++ object and
fills all fields. C sequences and Strings use actual SDK init/fini/assignn.
Only after complete fill is ownership committed: genuine C POD ownership is
swapped and old destination ownership is finalized; C++ whole move assignment
must be statically noexcept. Allocation failure12 destroys the private value
and preserves the original destination. No partial mutation is committed.
The destination must already be a valid initialized or genuine zero-valid C
ownership object, never arbitrary bytes or a C++ object of the same shape.
Original empty native placeholders must be0 even for logical wire0.

The original C GetTypeDescription server handler itself calls Response__init.
It must receive zero-valid storage from the separate lifecycle port, not a
preinitialized `__create` object that would be initialized twice. Final shared
ownership must call actual C__fini exactly once, after all original users/send
complete. Encode never prematurely frees original request/response storage.

## Publication, composition and lifetime

The C APIs are in `uwvm_rmw/default_control.h` and `codec_composer.h`. Registry
export is sticky. Published destruction returns17; there is no fake C-profile
uninstall. Creation/destruction is exclusive cold bootstrap. Diagnostic/export
output slots are distinct caller-owned writable memory, not overlapping slots.
All actual SDK code, registry/table owners and callback/profile storage remain
alive and nonmoving through every borrower and physical Source retirement.
No Host process singleton survives between Source generations.

Original B selection requires a contiguous descriptor table with service child
pointers inside it. A copied old validator cannot authenticate a clone at its
new address. Composer reserves one bounded copy table, copies immutable names,
maps every original child, and rewires cloned roots. Each clone validates its
own address/fields and the unchanged original snapshot, then delegates to the
**original** callback at the **original** descriptor address. It owns its real
validation_state; it does not fake native TypeSupport or original owner state.
Duplicate names/pointers/missing children refuse. Original tables/owners are
borrowed and must remain alive; publication never turns a naked C pointer into
automatic lifetime ownership. This supports explicit composition with the
existing independently exported C++ Registry without changing either table.
