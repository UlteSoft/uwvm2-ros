# SDK repository

The SDK has moved to [UlteSoft/uwvm2-ros-sdk](https://github.com/UlteSoft/uwvm2-ros-sdk).

This repository contains the **uwvm2-ros virtual machine**. Language bindings,
platform SDKs, examples, development manuals, precompiled toolchains and Wasm
language runtimes are maintained in the separate SDK repository.

Clone the SDK with Git LFS enabled to obtain its precompiled development inputs.
See the SDK repository README for installation and the current qualification
status. Running a generated module requires uwvm2-ros and explicitly configured
WASI/ROS permissions.

SDK 已迁移至独立仓库。当前仓库维护底层虚拟机；SDK 的源码、示例、文档、
预编译工具链和 Wasm 解释器均在新仓库维护。请启用 Git LFS 获取完整开发文件。
