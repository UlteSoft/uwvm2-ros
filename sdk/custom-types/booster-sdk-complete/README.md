## Choose exactly one generated build domain

All `bounded_records.*`, any `bounded_interfaces.*` and this generation proof
belong together. The C include guard, native-name-based symbols, layouts and
native traits are intentionally shared across consumers of one catalog. Include
exactly one such directory in a physical Guest/Gateway/native build. A single
application communicating with multiple vendors must merge and deduplicate the
complete catalogs with compatible bounds, then regenerate once. Concatenating
independent generated headers is not that integration.

For C/C++, add this directory and `sdk/include` to the actual WASI compiler's
include paths. Include `bounded_records.h` for C11 or `bounded_records.hpp` for
C++20. C values use counted text/sequences and the generated `_valid`,
`_wire_size`, `_encode` and `_decode` functions. Every active field is checked;
C++ `roswasmcpp::Codec<T>` delegates to the matching C implementation and commits
only complete owned values. Include the matching `bounded_interfaces.h/.hpp`
when the selected family has services/actions. The concrete raw command,
Publisher and Subscription examples in the vendor kit use these actual names;
they do not use a host ROS struct image. No network/clock/file right follows
from an include or constructor.

For Rust, use the actual `sdk/rust` crate with explicit `alloc` and `ros2`
features. Compile `bounded_records.rs` as its own application module. The real
record implements `roswasm::typed::Canonical` and provides checked `wire_size`,
`encode_into` and `decode`; enable the actual SDK transport independently. For
families with RPC sources, place `bounded_interfaces.rs` beside its matching
records and use the matching core service/action SDK roles. A native JVM,
Python process or host ROS library cannot substitute for that Wasm route.

For JavaScript, import the exact named `*Codec` export from
`bounded_records.mjs`. `defaultValue()` constructs an owned value;
`encode(value)` validates all fields before output allocation and
`decode(Uint8Array)` refuses malformed/trailing input before publishing a value.
64-bit integers stay `BigInt`. The records module performs no I/O. Select the
actual QuickJS/Javy-in-Wasm SDK/producer separately; a host Node codec check is
not a Wasm ROS delivery result. RPC families also supply their matching
`bounded_interfaces.mjs` and require the matching core Session/Capability
transport with each explicit service/action role alias.

For AssemblyScript, keep this installed directory at exactly one level below
`sdk/custom-types`: its real `../../assemblyscript/codecs` import resolves into
the SDK there. Use the exported complete record and `*Codec` classes and their
`encodeChecked`/`decodeChecked` status-bearing APIs. Finite arrays/sequences and
all late fields remain checked. Moving this file without changing and reviewing
its import context is invalid. The actual AssemblyScript ROS backend and Wasm
compiler remain explicit application selections.

For TinyGo, place the matching `.go` sources together in one `customtypes`
package. Their actual backend import is `uwvm2.local/roswasm`; resolve it to the
real `sdk/tinygo` module in the application's `go.mod`. Select the `ros2` build
tag with the genuine TinyGo Wasm target. `WireSize`, `Encode` and the generated
`Decode*` functions validate complete values and return errors rather than
partial objects. A Go tag does not enable a Runtime permission.

## Authority, lifetime and full values

Start with no ROS grants. The vendor raw import example expects error13 and an
unchanged eight-byte output sentinel before any input read or publication.
Positive operation uses a separately selected artifact and explicit individual
aliases, exact resource/type/native/canonical identities and finite limits.
Keep submit outcome, close/rollback result, native transport retirement and
physical controller stop separate. A timeout after send is unknown and cannot
trigger an automatic retry. Use only controller-approved complete input values;
a zero position/torque vector is not a generic stop protocol.

The native exporter sources in this directory are build inputs, not executed
proof. The original selected declarations and license/package notices are kept
in the vendor kit; their licensing terms continue to apply. Original private
paths inside the retained preparation receipt are historical acquisition/source
provenance, not paths silently opened by these codecs or permission grants.
