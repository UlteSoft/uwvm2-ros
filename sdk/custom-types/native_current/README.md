## Source-proof and linker-mode closure successor

The actual captured catalog now supplies every interface category from its
original `.msg`/`.srv`/`.action` extension, native type category and name. The
proof must retain that exact category, an actual integer ROS backend, and every
request/response/goal/result/feedback owner/type/identity. A proof cannot relabel
an actual Service as Message to omit its mandatory protocol trait. Required
traits are selected from these catalog facts, after independent complete proof
association; a floating-point `2.0` is not the integer backend `2`.

The concrete modern link oracle also checks compiler/EXE/required-link inputs
and the actual selected target link closure for unresolved-symbol relaxation or
partial-link modes. This includes transitive/aliased target link options,
libraries and relevant imported/configuration link interfaces. Normal cross

a general rejection of ROS distributions/architectures, a CMake sandbox or a
proof against a malicious compiler. The selected toolchain remains trusted.
Actual compiler/link/whole-MD/SDK evidence and later Native execution are still
required. No old unsupported gate or Guest permission changes.

Four additional authored source-policy groups use actual preserved catalog/
proof data for kind/backend/component negatives, and the real CMake string-mode

The follow-on link-input correction treats real CMake option lists as one
logical token stream. It inspects adjacent arguments after normalizing the
