# MoonBit ROS ABI and bounded client source

The pinned MoonBit **0.10.15+943464bfa** SDK supplies all 38
`uwvm_ros1_v1` and all 43 `uwvm_ros2_v1` raw numeric declarations, canonical
byte helpers, explicit Session/Node ownership and a finite guest-thread executor.
The 2026-10-19 Linux checkpoint compiled the current SDK and executed its local
models and default-disabled Runtime examples. Positive native ROS delivery,
complete official rcl/rclcpp/rclpy/rcljava parity and language debugging remain
separate, unfinished acceptance lanes. See the current results below and the
[complete retained evidence](../../test/0050.high_level_languages/results/native-budget/language-runtime-control-edges-20261019/README.md).

The maintained high-level-language producer/harness is owned separately. Its
existing portable MoonBit fixture uses real numeric imports and inline Wasm
loads/stores. This candidate follows that source-level FFI rather than assuming
a managed object layout. The pinned core archive SHA is
`96d30f4dbcc6a9e1736ef26fbdd0e8fb0e97cb01d50e55d2a0072208b8061ae5`.
Its actual builtin interface declares `UInt64`, conversions, Bytes, Result,
UTF-8 and floating-point operations used here. Official current documentation
describes the numeric FFI; acceptance here is tied to the actual pinned compiler and generated bytes.

## Exact imports and separate backend packages

Import `uwvm/ros/ros1` or `uwvm/ros/ros2`. Each package has only its own raw
namespace; selecting ROS1 never falls back to ROS2 or requires ROS2 imports.
The memory index is Int/i32. **Every handle, offset, length and capacity is
UInt64/i64, including wasm32.** Raw callers may select a memory explicitly;
the copied convenience layer always selects actual memory0. Out slots are
eight little-endian bytes, not native Java/MoonBit object references.

`raw.mbt` matches `sdk/abi/abi-v1.json` exactly. `abi_coverage(index)` is an
explicitly exported compile/import-inspection probe. Its valid cases use zero
placeholder addresses and handles and **must never be executed**. An unknown
index returns95. Retaining this probe prevents optimizing an unused function
out of the complete inventory. The normal examples do not call valid selectors.
The post-link verifier must resolve every type index and verify all 38/43 actual
function signatures, not just import names or WebAssembly magic bytes.

There is no Guest debug/update/policy import or management interpreter. WASI
stdout in the examples is inert data and supplies no ROS or management rights.

## Real linear arena and linker obligations

`linear/linear.mbt` contains explicit `memory.size`, `load8_u`, `store8`,
`i64.load` and `i64.store` instructions. Bytes are copied individually between
managed values and a separate ordinary wasm32 memory. GC arrays/strings are
never converted to offsets, and `externref` is never used as an address.

| Role | Byte interval, exclusive upper endpoint |
| --- | --- |
| Example ASCII stdout descriptor/padding | 0..16 |
| Example ASCII marker + newline | 32..289 |
| Canonical input | 65536..4259840 |
| Copied output | 4259840..8454144 |
| u64 slot and reserved padding | 8454144..8454160 |
| Compiler heap lower bound, linear backend | 8519680 |

Examples declare memory minimum256 and maximum1024 pages, export memory as
`memory`, use no shared/imported memory and disable GC JS string builtins.
The linear backend heap starts at8519680. The GC backend retains managed
objects as references and uses this explicitly configured ordinary memory for
copies only. The arena never grows memory or retains a borrowed view. A final
artifact checker **must** prove the compiler's data segments/heap do not overlap
these reservations; the source constants alone are not that artifact proof.
Do not embed this SDK in an unrelated module without preserving those ranges.
Current runtime check proves only at least130 pages are present; post-link
minimum/maximum, identity and non-overlap proof are additional mandatory gates.

Each call rejects input above4193786 or output above4194304 bytes before the
raw import. Smaller trusted quotas still apply. One shared arena lock rejects
reentrant use with17, including use across both backend packages. Import
closures are synchronous and non-raising and call no user callback. A Wasm
trap aborts the instance; this library claims no trap recovery or replay.

Poll/RPC seed the eight-byte length slot to UINT64_MAX. Success must overwrite
it with a value no greater than the caller's capacity. Only error90 with an
overwritten sentinel exposes `Reply.required`; all failures have empty public
data. It is a diagnostic, never an instruction to resize and retry. An event
may already have been consumed or a timed-out operation may have effects.
Fixed-size handle/request-ID/ready32 replies use separately declared capacities.

## Ownership and application methods

`new_session()` checks actual ABI1 and arena availability and creates no handle.
`Session.node(label)` supplies only a local label. `Node.open(alias, operation)`
uses the exact explicit UTF-8 alias and records a real successful nonzero handle.
Up to1024 complete owner reservations (including failed opens/retired records) are tracked; aliases are at most255 UTF-8 bytes and
contain no NUL. Operation selection is an immutable local enum and never alters
trusted resource/type/QoS/connection/quotas. There are no default grants.

`Resource.write`, `activate`, `poll`, `request`, `watch`, `poll_v1`, `ready` and
`submit` cover every existing raw form. Unsupported local operation/form pairs
refuse with95 or22 before any business import. Graph, parameter, TF, clocks,
lifecycle and logger operations use the same exact enum and canonical Bytes
interface; typed application-specific decoders remain explicit caller work.

Conveniences are `Node.publisher`, `subscription`, `client`, `service`,
`action_client` and `action_server`. Multi-alias server/client factories acquire
all separately requested roles before activation and close every earlier owner
once on failure. Service/Action server alias pairs and all four Action client
aliases must be nonempty and pairwise distinct BEFORE the first reservation or
native effect. Exact UTF-8 validation of the complete group still precedes its
first real acquisition; no role is repaired by inventing a new alias. A requested role is never silently omitted. ActionClient tracks
up to1024 actual returned nonzero goal IDs, rejects unknown owned-goal use, keeps
cancellation separate from terminal consumption, and never opens cancel-any.
ActionServer and ServiceServer response helpers prefix the actual nonzero ID
and invoke a separately authorized responder. Callback concurrency/native ROS
thread entry, hidden futures, clocks, threads and automatic retries are absent.

`close()` marks the shared local owner retired **before** the real close call;
a later cleanup error cannot resurrect it. `revoke()` first retires every local
same-Session/same-alias sibling, then calls the actual host. A later local reopen
of that revoked alias is refused13; the host remains responsible for every other
Session and the complete Instance/backend revocation boundary. There is no grant.
`Session.shutdown()` rejects a leased/retiring group with17 **before any mutation**.
Otherwise it retires all remaining owners in reverse acquisition order and
returns `CleanupReport {code,outcomes}`. Check `cleanup.code`; inspect every
outcome's alias/actual handle/attempted/previous/completed/code. The primary factory error
is retained separately from all rollback outcomes in `session.last_cleanup()`.
`session.cleanup_history()` retains each reserved report; `started=false` means
no cleanup was attempted with that reservation. A later shutdown cannot erase
the earlier factory report. `previous=true` carries an earlier close status
without replaying it; shutdown summaries also retain those earlier failures.
`session.retirements()` exposes every owner's last attempted close/revoke,
including incomplete attempts; statuses are stored in already-reserved scalar
fields. A first failure never hides the later failures. No finalizer conceals
cleanup status. Executor borrows its sources; Session owns handle retirement.

Open preparation allocates and registers a zero-handle pending owner before any
host import. `linear.admit_u64` copies the alias, seeds a zero output handle and
commits a real successful nonzero full-width u64 without allocating Bytes or
wrappers after the host effect. The success Result already exists. Multi-role
factories also preallocate their wrapper, success result and all rollback rows
before their first acquisition; every acquired role remains in the Session
ledger. This removes the post-success wrapper/list allocation obligation rather
than pretending to catch MoonBit allocation traps. All raw status/validation
failure branches retain explicit cleanup obligations and never replay open.
A terminal Wasm trap still needs actual Runtime/Host instance retirement; it is
not converted into an ordinary SDK error or a false cleanup-PASS report.

The executor registers at most64 sources and executes one poll per source per
pass. It passes an owned Bytes copy to the callback after releasing the arena.
A complete upfront validation of every source and distinct Session precedes any
poll or lease mutation. Same-Session leases cover the entire pass, including
owned-copy decoding and callbacks, so callback-triggered shutdown/close/revoke,
reentrant executor passes, resource activation or new opens refuse17 before
changing any owner. Ordinary granted publish/respond work can still run after
the poll arena has been released. Registration, recursion and executor close
during a pass are refused. Native poll11 is idle; **callback11 is an error**. Callback functions return status and are not
declared raising. A process/Guest trap requires the actual owner cleanup path.

## Canonical helpers and explicit remaining work

`wire` provides full-width u64, i32, exact Bool, strict String, finite48-byte
Twist, Trigger/SetBool Bool+String responses, nonzero ID prefixes, bounded
Fibonacci goals and complete feedback/result envelopes. UTF-16 is validated and
the UTF-8 size is counted before the pinned core encoder can allocate or panic
on malformed surrogate input. BOM and embedded NUL message bytes are preserved.
The pinned core's actual `drop_utf8_bom` removes the prefix only when
`ignore_bom=true`; this package explicitly passes false and preserves it.
Application alias validation is separate and rejects NUL. Fibonacci count<=48
matches the actual Runtime validator and ROS2 Gateway, not a guessed47 bound.
Action receive methods check the exact returned full-width ID and terminal
kind2/3/4 before local goal retirement; mismatches expose no payload. Goal slots
are reserved before send admission. Own cancellation requests capacity1 and
checks an exact Bool result; it does not consume terminal ownership.
Arrays/counts and trailing bytes are checked by the selected complete codec;
typed native identities are never invented here.

Additional typed Image/Transform/parameter/unified-event/custom generated type
facades and optional scheduling are required follow-ups. The byte-level enum
and complete raw ABI are present; this first package does not claim those extra
typed facades or native rclcpp compatibility. Generated vendor codecs require
their own exact native identities and complete schema/closure validation.

`wire_test.mbt` contains 26 pure codec methods and `linear_wbtest.mbt`
contains 14 memory/error/copy/admission methods. Each backend has 13 local ownership
precondition tests (26 total). These 66 methods passed on both targets in the
current default model profile; the optional owned-service profile adds four
private protocol models per target.
Synthetic scalar IDs in the ownership tests are never sent to any import. Those
methods establish local preflight/state expectations only, not native ownership.
Internal test closures are explicit models, not native bridges. Actual test linking must retain the same
arena reservation; a default one-page test module is not a valid substitute.
`producer-contract.json` records exact future build/artifact/Runtime obligations
with all actual result fields null. No test count is claimed as passing.
