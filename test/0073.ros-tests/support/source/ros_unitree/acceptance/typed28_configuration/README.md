## Derivation and independent admission

The maker derives all14 Guest binary/individual receipt associations, selected
Worker binaries, three native generation/export/Gateway associations and their
input labels directly from unchanged producer documents. Native identity strings
come only from actual exporter/generation documents. It reopens the selected
full-MD sections and original complete-source manifest references with separate
historical/current physical facts.

Root candidates come from recorded complete producer inventories, original
complete source plus manifest directories, exact producer output directories,
actual generated registry directories and the selected Cyclone profile directory.
Only a genuinely observed complete ancestor can replace redundant descendants.
The maker never guesses a broad parent to make the count fit. Exact Native
execution-view roots and Worker host catalog roots remain separate mandatory

The controls directory contains selection, config and an unexecuted literal
invocation. All files are written before it becomes a complete input root.

frozen `typed_transport_inputs.admit`. This independently consumes the real
receipts, reparses binary boundaries, verifies original source labels and
complete native/host catalogs, and checks the actual current loopback namespace.
It never calls the session runner and requires an empty actor list.

All current bootstrap inputs, selected planning files, complete source and
Frame inventories are rechecked before acceptance. The maker itself uses at
most1536MiB, guards actual64GiB/swap0/cpus0–31 with four-GiB cgroup headroom,
