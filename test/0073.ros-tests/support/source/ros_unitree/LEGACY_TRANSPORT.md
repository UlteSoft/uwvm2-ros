# Six-language ROS1 TCPROS acceptance

`run_legacy_transport.py` is the maintained executable consumer for the six
same-main legacy commands. It runs twelve serial cases: a fresh default-denied
instance and a fresh explicitly authorized instance for each C, C++, Rust,
TinyGo, AssemblyScript and embedded JavaScript command. It consumes real build
results; it does not compile, acquire packages, fabricate native identities,
replace ROS1 with ROS2, run a simulator or contact a physical robot.

The source has been authored and syntax-parsed only. No TCPROS execution result
is claimed by this document. A successful build remains preparation evidence
until the actual runner and its independent outer owner complete all checks.
Missing prerequisites fail admission before any actor or network namespace is
created. Do not replace a missing report with a hand-written success JSON.

## Closed control selection

not executable as supplied: `parent_network_namespace` must be replaced with
the actual current `/proc/self/ns/net` value, and every label must name an
ordinary input in the SHA-bound Unitree configuration. Input pins contain the
actual path, complete SHA256 and size. The selection cannot carry an arbitrary
native MD5, grant, command suffix, preload, interface, environment or external

`reports` names four actual report inputs: `native_products`, `workers`,
`commands`, `exec_gate`. `workers` selects the real `ros1` and `dual` binary

`receipt`, and either `ros1` or `dual` as `worker_profile`. `exec_gate` names its

`mappings` names nonempty input-label lists for `master`, `peer`, `peer_context`,
`gateway`, `gateway_context`, `gate`, `worker_ros1`, and `worker_dual`. Each

The configuration must select the **whole native producer output root**, whose
