# Service Host contracts (source only)

All checks here are authored and unexecuted. No candidate import, generator,
compiler, model, Runtime, SDK probe, native ROS or SSH operation was performed by
the author. The standalone target only exercises actual pure helper values; it
provides no fake Runtime/Native implementation and no ROS acceptance claim.

`value_contract.cc` has 27 named groups. It checks independent pending/primary/
cancel/commit/cleanup facts, preserved borrow history, operation-specific empty peek11
with no visible borrow, private ticket prefix restoration, same-record logical event
projection, missing native metadata refusal, legitimate zero-valued native data,
control semantics, empty canonical requests, independent availability peer and
exact sequence/nonce ACK association. Assertions remain active in Release.

An independent executor can configure the standalone CMake project with an
actual complete reviewed `UWVM_SOURCE_ROOT`, build `rmw-service-host-values`, then
run it in an owned finite resource/process group. CMake contains no `try_run`,
`add_test`, network acquisition or automatic execution. Capture exact compiler
inputs, actual target/MD/link evidence, stdout/stderr/return and cleanup; the
expected marker includes `groups=27` and an actual positive runtime check count.
Do not substitute an expected check count for the number really executed.

`host_signature_contract.cc` has twelve actual C++ type assertions. Compile it
only with the genuine current Runtime's complete include/flags/configuration
closure and `UWVM_IMPORT_ROS2`; do not create Runtime stubs. It is deliberately
not in the small pure-value CMake target. The existing independent
`test/0073.ros-tests/support/source/ros_rmw_service_transport/raw_signature_contract.c` checks all twelve
actual C raw declarations using C11 `_Generic`; its source stays unchanged.

`test_import_checker.py` has eight authored methods. Its numeric Wasm fixtures
exercise the actual fixed neighboring SDK binary parser/checker: all twelve,
partial inventory, i32 memory versus i64 offsets/handles, wrong backends,
duplicates/results, optional namespace selection and explicit non-ROS allowance.
An independent source-admitted test owner may run it; this author did not import
or execute it. The fixture bytes contain imports only and never execute Wasm.

Use `sdk/origin/tools/check_rmw_service_imports.py` on an actual independently validated
artifact, with `--require-all` only for a deliberately full raw inventory.
Publisher, subscription and legacy availability namespace allowances are separate
flags. Binary signature success is not a full Wasm validity or native proof.

The full Runtime/Guest/native failure matrix is described in
`sdk/origin/abi/RMW_SERVICE.md`. It remains mandatory future actual execution, including
atomic output sentinels, exact raw12 caller authority, independent observer and
availability permissions, response/control quotas, same native object identity,
all cleanup outcomes and authenticated session loss. These 27 value groups and
eight parser methods do not increment any previously executed suite count.

The eight r2 groups exercise production helpers for actual bound-key selection,
source/responder/query absolute entry deadlines, preserved RPC0 versus Host/API22,
local preflight without a main RPC attempt, and bad_alloc12/other5 compensation
routing through the ACTUAL post-association helper. Fault callbacks record only
pure values; they implement no Runtime, native provider or pretend cancellation.
A real native cancel/timeout/session/Guest-output regression remains required.
