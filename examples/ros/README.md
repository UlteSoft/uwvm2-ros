# All twenty original examples

`catalog.json` preserves the exact original20 lesson identities. Existing WAT
sources remain unchanged. `materials.py` emits one complete English material
folder per lesson: source pins, full compilation commands, a complete uwvm
argv, all explicit permissions/limits, mirrored Gateway configs, expected
output and actual independent-native test recipes. It executes no command and
reports PREPARED_NOT_EXECUTED. Material generation is not acceptance evidence.

Supply absolute source/manifest/output/Worker/wat2wasm/socket/rootfs paths, the exact
owned Worker PID and both trusted UIDs. `--native-products` names a physical
JSON object mapping backend1/2 and gateway/topic/resources/action/tf/five to objects
with exactly `origin` (physical qualified product path) and `guest_path`
(canonical absolute path in that backend's owned rootfs). Those products must
be staged at the emitted absolute guest paths
inside their rootfs before execution. Bind the owned output/config and socket
directories at their same absolute paths inside each private rootfs. Complete
clean-environment Gateway and native argv are emitted with each lesson. The trusted supervisor reserves ports
11339/11379 and domains73/79, maps current immutable ARM products, holds the
PID across exec and removes only owned resources. Never start a second Master
on an occupied port or use a stale example PID to authenticate another process.

Both `--ros1-gateway-report` and `--ros2-gateway-report` are required fresh
strict targeted compilation reports for the exact Gateway `origin` products,
source/manifest and selected rootfs SDKs. The renderer calls the same
`qualify_gateway` and `gateway_library_environment` helpers as the actual lanes.
It preserves their opened-file inputs and records complete before/after SDK
inventories and root aliases. A report's status alone is insufficient. Keep
those products, evidence files, source and SDKs immutable after rendering and
through execution; generation does not reserve or lock the later run's inputs.

The emitted Gateway `env -i` includes only the loader helper's explicit
`LD_LIBRARY_PATH=/opt/uwvm-custom-types/lib` when qualified custom native links
require it. A header-only ROS1 selection receives no loader entry. The helper
checks the complete custom-library directory and pinned ARM shared objects; it
does not claim a complete ELF `DT_NEEDED` graph. No ambient loader prefix,
custom setup hook or ROS/WASI grant is inherited. Original native probe
commands receive no custom loader setting. Activating the already bound distro
setup remains explicit in each command. The material job's 180-second budget
includes these read-only qualification and SDK-preservation scans; it changes
no Guest, native ROS or Runtime timeout. Its result remains
`PREPARED_NOT_EXECUTED`, including after successful product qualification.

Example15 and16 contain the complete simultaneous WASI Group `basic_io`, ROS1
Group `legacy_sensors`, ROS2 Group `modern_planners`, ROS1 controller Single
and two independently configured hybrid Singles. Group membership shares an
explicit policy; it does not share opaque handles, per-Instance quota buckets
or authenticated sessions. The original camera modules invoke real starts,
cross-module exports and a foreign-handle attack. No module label is accepted
as an IPC credential and no global current_module_name is introduced.

The unauthorized lessons intentionally use a separately authorized subscribe
handle for an unauthorized publish, expecting13 and unchanged sentinels.
The new six-language absent rows additionally test an entirely empty ROS grant
table. The cross-module attack expects9 when main uses provider's real opaque
handle. Every negative needs independent actual native message/endpoint counts,
not merely the expected errno. Basic WASI stdin/stdout/stderr are the default;
only fixtures importing the monotonic clock explicitly receive that right.
No filesystem, process, thread, random, socket, environment or ROS right is
silently added. Disabled-test ROS2 examples prove no signed Enforce property;
the independently signed security suite remains mandatory.

Compile/run all lessons in the parent's current 64 GiB, swap-zero cgroup lane after
the full source and products are frozen. Keep native/Guest logs, complete byte
comparisons, actual Worker/Gateway mappings, same-incarnation OOM and cleanup
with each result. A successful source renderer or a prior historical lesson
receipt cannot satisfy the current twenty-example acceptance mapping.
