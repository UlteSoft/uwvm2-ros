These three files retain the exact builder, official C++ object qualifier and
utility bodies used by the reviewed seven-role payload. They are preserved
here so a local temporary-directory reset does not lose the actual source.
`source-ready.json` records complete byte counts and SHA256 values; copying
them here does not run them or qualify any product.

The parent acceptance directory maintains the metadata maker, explicit
historical/current observation adapter, restart helper, independent Root owner
and source stager. Read `../TYPED_POSTBOOT_CONTROLS.md` before constructing a
source payload. Each phase requires actual physically staged file selections
and the admitted Linux cgroup. Never invoke this compiler worker directly to
bypass its owner, manufacture a future pin, reinterpret an old failed batch
as a pass, or treat binary validation as DDS/Runtime acceptance.

The builder preserves original source and compiler contracts, requalifies nine
completed old products and compiles five remaining products with14 actual
compiler tool invocations. Its separately reviewed adapter keeps old receipts
and current file observations apart. The qualifier reopens the retained
official object and full dependency proof. Neither grants Guest permissions.
